# INTENT — wiki-docs v0.1

## 목적·범위·기대 결과

- 목적: 위키의 뼈대와 규칙을 만들고, 실제 질문 하나로 "위키 검색 → 외부 검색 → 확인 후 저장" 흐름이 처음부터 끝까지 한 번 동작하게 한다.
- 범위:
  - 위키 구조와 페이지 양식.
  - 질문 → 검색 → 저장 흐름.
  - inbox 원본 정리. 원본은 사람이 넣거나, 사람의 요청으로 에이전트가 넣는다. 마크다운 문서를 담은 폴더와 유튜브 영상의 자막·요약을 다룬다.
  - 노트북·데스크탑 동기화.
- 기대 결과: 위키 뼈대와 작업 규칙이 있고, 실제 질문 하나가 위키 검색 → 외부 검색 → 사용자 확인 → 위키 저장까지 거쳐 위키 페이지로 남아 있다.

## 배경

프로젝트를 정식 프로젝트로 승격하고 루트 INTENT를 다시 정했다.
분야는 아직 정해지지 않아서 필요할 때 늘리기로 했다.
위키는 "물으면 위키에서 먼저 찾고, 없으면 외부에서 검색하고, 확인받아 저장하는" 방식으로 쓰기로 했다.
첫 버전에서는 이 흐름이 실제로 동작하는지 확인하려고 한다.

## 제외 범위

- 기존 문서 일괄 이전.
  노트북·데스크탑에 있는 마크다운을 한꺼번에 위키로 옮기지 않는다.
- 자동 실행.
  정해진 시간에 에이전트가 스스로 검색·정리·갱신하지 않는다.
- 여러 에이전트 분담.
  herdr scouter에게 검색·정리를 나눠 맡기지 않는다.
- 웹 사이트로 게시.
  위키를 별도 웹사이트나 검색 화면으로 만들지 않는다.
