# SPEC — wiki-docs v0.2

## R-1. 위키 페이지는 모두 wiki/<분야>/<소스>/에 있고, 빈 폴더와 apps가 없다

**요구**

페이지는 `wiki/<분야>/{youtube,web}/` 아래에 둔다. 분야 폴더 바로 아래에는 `index.md`와 소스 폴더만 둔다. `apps` 분야는 두지 않는다.

**정해진 결과**

`wiki/<분야>/` 바로 아래에 `index.md`가 아닌 `.md` 파일이 없다. 소스 폴더 이름은 `youtube`·`web` 중 하나이고, 소스 폴더마다 페이지가 하나 이상 있다. `wiki/apps/`가 없다.

**판정 방법**

`wiki/` 아래 폴더·파일 목록을 본다.

## R-2. 페이지 위치가 그 페이지의 소스와 맞는다

**요구**

`sources`가 한 소스에서만 온 페이지는 그 소스 폴더에, 둘 이상의 소스가 섞인 페이지는 `web/`에 둔다. 저장소 안 기록 문서는 소스 종류로 세지 않는다.

**정해진 결과**

`youtube/` 페이지의 `sources`는 유튜브 원본 raw 경로·YouTube URL만 가리킨다(저장소 안 기록 문서 제외). 그 밖의 페이지(웹 정보만, 또는 두 소스가 섞임)는 모두 `web/`에 있다.

**판정 방법**

페이지마다 `sources`의 종류를 세어 폴더와 대조한다.

## R-3. inbox·raw의 원본 폴더 이름이 YYMMDD-{소스}-{title}이고, raw는 분야 아래에 있다

**요구**

inbox 원본 폴더 이름은 `YYMMDD-{youtube|web}-{title-in-english}`이고, 정리한 원본은 `raw/{youtube|web}/YYMMDD-{title-in-english}/`에 있다. 날짜는 inbox에 넣은 날이고 raw로 옮겨도 그대로다. raw는 분야로 나누지 않는다(D-12).

**정해진 결과**

`inbox/` 바로 아래 원본 폴더 이름이 `^[0-9]{6}-(youtube|web)-[a-z0-9-]+$`에 맞는다. `raw/` 바로 아래에는 `youtube`·`web`만 있고, 그 아래 폴더 이름이 `^[0-9]{6}-[a-z0-9-]+$`에 맞는다.

**판정 방법**

폴더 이름을 정규식으로 검사한다.

**출처**

## R-4. 원본 파일의 내용과 이름은 바뀌지 않는다

**요구**

원본 폴더의 이름·위치를 바꿀 때 안의 파일 내용과 파일 이름은 그대로 둔다.

**정해진 결과**

이름을 바꾼 원본 폴더의 파일이 모두 git rename 판정 R100이고, 폴더 안 상대 경로가 같다.

**판정 방법**

`git diff -M --name-status`로 R100인지, 옮기기 전후의 파일 상대 경로 목록을 비교한다.

## R-5. 분야 index가 소스별 제목 아래에 실제 페이지를 빠짐없이 링크한다

**요구**

`wiki/<분야>/index.md`에 페이지가 있는 소스만 `## youtube`·`## web` 제목을 두고, 그 아래에 그 소스 폴더의 페이지를 링크한다.

**정해진 결과**

각 소스 제목 아래 링크 목록과 해당 소스 폴더의 페이지 목록이 같다. 소스 폴더에 `index.md`가 없다. `wiki/index.md`의 분야 목록과 분야 폴더 목록이 같다.

**판정 방법**

index의 제목별 링크와 폴더 목록을 비교한다.

## R-9. 유튜브 페이지는 영상별 섹션을 등록일 최신순으로 둔다

**요구**

유튜브 원본을 `sources`로 가진 페이지는 영상마다 `## YYYY-MM-DD · <영상 제목>` 섹션을 두고, 등록일이 최신인 섹션이 위에 온다. 등록일은 그 영상 `meta.json`의 `upload_date`다.

**정해진 결과**

그 페이지의 영상 섹션 수가 `sources`의 유튜브 원본 수와 같다. 섹션 날짜가 위에서 아래로 내림차순이고, 각 날짜가 해당 원본 `meta.json`의 `upload_date`와 같다. 페이지 맨 위(첫 영상 섹션 앞)에 요약이 있다.

**판정 방법**

섹션 제목을 정규식으로 뽑아 정렬을 확인하고, `meta.json`의 `upload_date`와 대조한다.
